# 用固定操作执行模型计划

本决定替代主执行流程中的自由 Bash 命令生成和模型验证命令。

模型只输出追问、拒绝或最多三个操作步骤。步骤参数按支持范围验证。程序读取真实文件、冻结源和目标清单，取得确认后执行，再用固定检查规则验证。

文件操作由 Python 标准库完成。全部路径限制在所选工作目录内，链接及特殊文件拒绝。删除进入可恢复回收区，同名目标保留两份。Linux 移动使用 `renameat2(RENAME_NOREPLACE)`；不支持或跨文件系统时明确失败。Windows 移动使用目标存在时会失败的 `os.rename`。

仅固定系统查询仍调用 Bash。CLI、JSON、批处理和历史重放都使用同一个操作执行入口。模型输出的旧命令不可执行。批处理只执行只读任务，文件修改始终需要人工确认。

旧命令审查模块保留供兼容接口和历史版本测试使用；它不再授权主文件执行流程。旧 Bash 评测资料保留作历史参考，新的主评测检查操作计划与独立文件结果。

工作区检查不是操作系统隔离。第一版适用于可信个人工作目录；不将面对恶意并发路径替换的共享目录作为已验证使用场景。
